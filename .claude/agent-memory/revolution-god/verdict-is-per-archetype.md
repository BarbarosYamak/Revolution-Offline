A PASS is for the archetype's whole intended day (prepare, earn, train, sell, bank, PvM/social, guarded end) proven live. A proven sub-loop with anything else unproven is PARTIAL PASS; a shard/owner dependency is BLOCKED.

**Why:** on 2026-09-05 I wrote "brew loop PASS" for the alchemist while its sale, bulk buying and gain were unproven; the owner asked "how do you pass if things are not fixed?".

**How to apply:** in every status table put the verdict in the archetype column and list what is still unproven beside it; sub-loop wins go in the evidence column, never as PASS.
