# M2.5 Scenario 2b -- the return leg, Britain to Yew.
#
# Same one line of intent in the other direction. Running it as a pair is what
# proves the world route graph is not a one-way fluke, and it is also how the
# character gets home between test runs without anyone typing coordinates.

say home again
