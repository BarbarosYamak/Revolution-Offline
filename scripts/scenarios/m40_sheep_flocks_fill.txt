# spawns exactly ONE creature per tick and then re-arms for

# been up for a long time.
#
# ISPV_START (CCSpawn.cpp:1255) is `pItem->SetTimeout(0)` -- it just brings the
# spawner's OWN next tick forward. Every sheep is still created by the engine's
# GenerateChar on the engine's own path, with the spawner's own MAXDIST=15
# placement. Nothing about the flock's rules is altered, only its schedule.
