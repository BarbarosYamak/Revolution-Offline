# M3.8 PHASE 1 -- force the EXACT M3.7 Minoc failure, not a convenient one.
#
# RUN AS SESSION 10 (RevolutionMiner).
#
# WHY THIS EXISTS
#
# m38_minoc_bank walked into the Minoc bank, reached the banker and walked back
# out -- `finished (30 steps)`, zero errors, one plan each way. That is NOT
# proof the M3.7 trap is gone. It is proof that one route on one occasion
# worked, and accepting it would be exactly the mistake this project keeps
# having to correct: reading a green run as a closed question.
#
# The M3.7 failure had specific geometry:
#
#   route exhausted at (2498,548,0)          <- stuck HERE
#   trying to reach (2488,552,0) (escape 1/3)   no path
#   trying to reach (2488,536,0) (escape 2/3)   no path
#   trying to reach (2504,536,0) (escape 3/3)   no path
#   ...and the original target was (2472,536)
#
# The banker sits at roughly (2503,557). The stuck tile is (2498,548) -- a
# DIFFERENT part of the building, five tiles north-west of where the clean run
# ever stood. So the clean run never visited the tile that failed.
#
# This scenario goes to that tile deliberately and then asks for the exact
# target that could not be reached, plus all three escape rungs in turn.
#
# WHAT A PASS AND A FAILURE EACH LOOK LIKE
#
# If the trap is gone, every leg reports ok=1 and the run finishes.
#
# If it is not, the new failure diagnostic says what the wall is made of:
#
#   [bot] start (x,y,z) exits: open=0 terrain=5 mobile=2 dynamic=1 door=0 ...
#
# openExits=0 means enclosed where it stands; the counts say by what. That is
# the difference between "decorated furniture seals interiors" (a real
# BLOCKS_M4 defect) and "two NPCs happened to stand in a doorway" (a transient
# the escape rungs should ride out). M3.7 could not tell those apart.

wait_world
sleep 2000
ensure_peace

use_moongates on

# ---------------------------------------------------- 1. stand ON the bad tile
# travel_point, not travel_service: the banker is not the target, the tile is.
travel_point 2498 548
wait_travel
expect_travel ok
sleep 2500

say standing on the tile that trapped the M3.7 miner

# ------------------------------------- 2. ask for the exact unreachable target
travel_point 2472 536
wait_travel
expect_travel ok
sleep 2000

say reached the original target

# --------------------------------- 3. back in, then each escape rung in turn
travel_point 2498 548
wait_travel
expect_travel ok
sleep 2000

travel_point 2488 552
wait_travel
expect_travel ok
sleep 1500

travel_point 2498 548
wait_travel
expect_travel ok
sleep 1500

travel_point 2488 536
wait_travel
expect_travel ok
sleep 1500

travel_point 2498 548
wait_travel
expect_travel ok
sleep 1500

travel_point 2504 536
wait_travel
expect_travel ok
sleep 1500

# ------------------------------------------------- 4. and out to open country
travel_point 2466 544
wait_travel
expect_travel ok

say every rung the M3.7 run failed, walked
sleep 1500
logout
