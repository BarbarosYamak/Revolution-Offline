#     [travel] plan Britain banker: no world route to the destination
#              legs=0 ~0 tiles transit=0 nodes=1
#     [travel] Britain banker FAILED at (1490,1555,30)
# from the Mage Tower's upper storey at z=30, with no escape attempt at all.
#
# WHAT SHOULD HAPPEN NOW
#
#   plan fails (NoRoute)
#     -> journey PARKS in Phase::Recovering and stays Active
#     -> the client owns movement and walks to a navgrid anchor
#     -> recovery reports back with an explicit event
#     -> the journey re-plans for the SAME destination and resumes
#     -> or, after three anchors, fails cleanly carrying the original reason
