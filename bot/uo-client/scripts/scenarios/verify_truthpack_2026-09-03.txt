# NOTE ON PROBE TECHNIQUE (learned from run vtp1): a player-typed "." command
# does NOT expand <...> in its arguments, so `.sysmessage <expr>` echoes the
# raw text.  Only the SHOW verb evaluates, because it runs the argument
# through r_WriteVal.  Every probe below is therefore `.show <key>` or
# `.<ref>.show <key>`.
#

# to any character's pack.  Observer's own CARTOGRAPHY is moved to prove the
# treasure-map threshold and restored to 0 at the end; no bot character's
# skills, stats, gold or inventory are touched.
