After Hector/Odessa/Aurelius cycle validation passes, ramp the live roster
20 -> 50 -> 100 bots, checking server performance and repeated stalls at
each step before the next. Never jump to 100 while loops are still being
diagnosed. Starting mix 70% combat / 30% crafting — a hypothesis to test
for demand, supply shortages and player trading, not a proven balance.
Crafting mix is chosen to supply combat builds: weapons, armour, potions,
bandages, scrolls.

**Why:** owner, 2026-09-06: "100 at once would make failures harder to
isolate"; the ratio exists to create real trade pressure between archetypes.

**How to apply:** when planning waves, stage sizes 20/50/100 with a
performance + stall check between; pick crafter archetypes by what the
fighters consume (smith, armourer, alchemist, tailor/bandage, scribe);
report the ratio's effect on trade so it can be revised. roster30 is only
30 chars — 50/100 needs new accounts/characters (creation randomises
skills; see creation-randomises-every-skill).
